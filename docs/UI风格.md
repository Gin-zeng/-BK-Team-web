# UI风格：学院球队战术室

当前实施方向：温暖、克制、适合长时间观看数据与战术的球队工作台。

基础色：暖白 #F6F5F0、纸白 #FFFEFA、深绿 #24463A；木色球场 #E4C598；陶土橙 #C06442 强调。球队主题色可在后台修改。

布局：桌面固定侧栏，顶部面包屑，主体分区；移动端抽屉导航、两列战术卡、单列教学布局。球场采用SVG，缩放不模糊。图表重视来源和样本说明。

视觉语义：进攻陶土橙，防守蓝；线条、标签与文字共同区分状态。战术画布优先，球员职责位于下方，适用场景和常见错误位于右侧。按钮文字明确，空状态不生成假数据。

最终风格已通过1440px桌面与390px手机真实截图检查并确定。首页与战术教学页无横向溢出，动画控制和球员职责可用。后续真实设备与大屏教学可按反馈继续调整字号和画布比例。
