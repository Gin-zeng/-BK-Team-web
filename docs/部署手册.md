# 部署手册（唯一生产站：www.jxlq.top）

> 定位：自 2026-10-22 起，`https://www.jxlq.top` 是**唯一生产站点**。
> 所有内容开发（DeepSeek / Codex / 人工）都围绕它进行；OpenAI Sites（`chatgpt.site`）不再作为生产目标。

## 1. 架构

```
GitHub main（唯一代码源）
        │
        │ npm run deploy:cf（构建 + 守卫检查 + wrangler deploy）
        ▼
Cloudflare Workers + D1 + R2（自有账号）
        │
        ▼
https://www.jxlq.top（国内直连可用）
```

关键文件：

| 文件 | 作用 |
| --- | --- |
| `wrangler.deploy.jsonc` | 部署配置：Worker 入口、ASSETS、D1(`DB`)、R2(`BUCKET`)、`www.jxlq.top` 路由。**唯一需要填的是 database_id** |
| `scripts/deploy-cf.mjs` | 部署守卫：校验 database_id 非占位符、dist 产物存在，然后调 wrangler deploy |
| `package.json → deploy:cf` | 一键命令：`npm run build && node scripts/deploy-cf.mjs` |

## 2. 前置条件

- Cloudflare 账号（免费计划即可）；
- `jxlq.top` 域名已实名（✅ 2026-10-22 已完成）；
- 本机 Node ≥ 22.13、依赖已安装（`npm run install:ci`）；
- 本机 PowerShell 能访问 api.cloudflare.com（`npx wrangler login` 需要浏览器 OAuth）。

## 3. 一次性初始化（按顺序，只做一次）

### 3.1 域名接入 Cloudflare

1. https://dash.cloudflare.com → Add a site → `jxlq.top` → Free 计划；
2. 复制给出的两个 NS（形如 `xxx.ns.cloudflare.com`）；
3. 阿里云 → 域名列表 → `jxlq.top` → 管理 → DNS 修改 → 粘贴这两个 NS；
4. 等 Cloudflare 状态变 **Active**；
5. NS 生效后 Cloudflare 会导入阿里云旧记录，**删除**这些已无用记录：
   - `www` CNAME → `custom-domains.chatgpt.site`
   - `_openai-site-verification.www` TXT
   - `_cf-custom-hostname.www` TXT

### 3.2 登录并创建 D1 / R2

```powershell
cd E:\篮球战术动画讲解平台\mech-hoops
npx wrangler login
npx wrangler d1 create mech-hoops-db
npx wrangler r2 bucket create mech-hoops-media
```

`d1 create` 输出里有一段 `database_id`，把它填进 `wrangler.deploy.jsonc`：

```jsonc
"d1_databases": [
  { "binding": "DB", "database_name": "mech-hoops-db", "database_id": "你的真实ID" }
]
```

### 3.3 建表（两个迁移都要跑，按顺序）

```powershell
npx wrangler d1 execute mech-hoops-db --remote --file drizzle/0000_dazzling_whistler.sql
npx wrangler d1 execute mech-hoops-db --remote --file drizzle/0001_outgoing_micromacro.sql
```

校验 9 张表：

```powershell
npx wrangler d1 execute mech-hoops-db --remote --command "SELECT name FROM sqlite_master WHERE type='table' ORDER BY name"
```

期望：admins, auth_bootstrap, auth_limits, email_codes, email_sessions, email_users, imports, records, uploads。

### 3.4 部署

```powershell
npm run deploy:cf
```

> 若域名还是 Pending，routes 会让部署失败。临时把 `wrangler.deploy.jsonc` 里 routes 一行注释掉再部署，
> 等域名 Active 后在 Cloudflare 控制台 Workers & Pages → mechanical-basketball → Settings → Domains & Routes 手工添加 `www.jxlq.top`。

### 3.5 配置 4 个密钥

```powershell
npx wrangler secret put RESEND_API_KEY    --config wrangler.deploy.jsonc
npx wrangler secret put EMAIL_FROM        --config wrangler.deploy.jsonc
npx wrangler secret put EMAIL_AUTH_SECRET --config wrangler.deploy.jsonc
npx wrangler secret put ADMIN_SETUP_TOKEN --config wrangler.deploy.jsonc
```

- `EMAIL_FROM`：Resend 已验证发信域名下的地址；
- `EMAIL_AUTH_SECRET`：≥ 32 位随机串；
- 4 个值可沿用 Sites 后台已配的那套。

### 3.6 初始化管理员

1. 打开 `https://www.jxlq.top/#admin`；
2. 走「邮箱验证码登录」，输入你的邮箱 → 收码 → 登录；
3. **首个验证成功的邮箱自动成为管理员**（无需口令）。

## 5. 内容维护（数据都在自有 D1 / R2）

- 后台入口：`https://www.jxlq.top/#admin`（邮箱验证码登录）；
- 数据导入：后台「导入数据」上传 xlsx/CSV → 映射 → 校验 → 保存草稿 → 分别发布比赛与球员；
- 录像/图片：后台「上传文件」，存 R2；
- 备份：定期 `npx wrangler d1 export mech-hoops-db --remote --output backup.sql`（含 schema+数据）。

## 6. 验证清单（每次部署后）

```powershell
(Invoke-WebRequest https://www.jxlq.top -UseBasicParsing).StatusCode
```

- [ ] 关代理 / 手机流量能打开首页
- [ ] 战术手册能播放动画
- [ ] 比赛、球员、录像（如有）能正常加载
- [ ] /#admin 邮箱登录可进后台

## 7. 回滚

- 代码回滚：git revert 后重新 `npm run deploy:cf`；
- 域名回滚：把 NS 改回阿里云，恢复原 CNAME 即可（国内直连会回到 403，一般不需要）。

## 8. 故障排查

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| deploy 报 database_id 占位符 | 未填真实 D1 ID | 按 §3.2 创建并填入 |
| deploy 报 routes/custom domain 错误 | 域名未 Active 或旧 CNAME 未删 | 删旧记录；必要时注释 routes 部署后手工加域名 |
| 页面 500 / 表不存在 | 迁移没跑 | 按 §3.3 补跑两个 SQL |
| 邮箱收不到码 | Resend 密钥或发信域名未验证 | 检查 secrets 与 Resend 后台 |
| 国内打不开、海外能开 | 自定义域名未生效或缓存 | 用 Resolve-DnsName www.jxlq.top -Server 223.5.5.5 核对，等 TTL 过期 |

## 9. 安全约定

- .dev.vars / .env* 永不提交（.gitignore 已覆盖）；
- 密钥只通过 wrangler secret put 注入，不进仓库；
- database_id 与 bucket_name 不是秘密，可放仓库；
- 发布前跑 npm run typecheck 与 npm test。

## 10. 与 Codex / DeepSeek 的分工约定

- **Codex / DeepSeek 负责改代码**，改完提交到 GitHub main；
- **部署统一走 npm run deploy:cf**（若 AI 环境无法跑 wrangler，由站长在本机执行）；
- 生产内容只维护在 www.jxlq.top 的 D1 里，不维护在 chatgpt.site。
