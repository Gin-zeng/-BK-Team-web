# 国内域名：选购、实名认证与 Sites 绑定操作清单

> 维护分支：`china-domain`
> 状态标记：✅ = 已核实事实；⚠️ = 待按平台实际界面核对

## 0. 背景与目标

- 现状站点：`https://mechanical-hoops-lab.quirkyfinch.chatgpt.site`（OpenAI 域名家族，国内大概率不可直连）。
- 目标：用**自己的域名**绑定 ChatGPT Sites，让国内用户通过自有域名访问。
- 预期管理：绑定后国内**能打开**，但流量仍走 Cloudflare 海外节点，速度时快时慢；想要稳定快速，需要后续「ICP 备案 + 国内托管/CDN」（见第 4 节）。

## 1. 阿里云域名选购（✅ 按万网现行流程）

1. 打开 https://wanwang.aliyun.com/ 或 https://www.aliyun.com/ 登录（支付宝/淘宝账号即可）。
2. 进入「域名注册」，搜索想要的名称（建议短、纯字母数字、避免连字符开头的名称，本项目 GitHub 仓库名曾误带前导连字符）。
3. 后缀选择（价格随活动浮动，以下为大致区间）：

   | 后缀 | 首年 | 续费 | 说明 |
   |---|---|---|---|
   | `.top` | 1–9 元 | ≈20–30 元/年 | 最便宜的稳定选择 |
   | `.cn` | ≈10–29 元 | ≈29–39 元/年 | 国内认知度高，必须实名 |
   | `.com` | ≈55 元（新用户优惠） | ≈85 元/年 | 最通用 |

4. 加入清单 → 结算 → 支付。支付成功后进入「域名控制台」。
5. **域名实名认证**（境内服务商注册域名必须做，否则会被暂停解析）：
   - 控制台 → 域名列表 → 找到该域名 → 「实名认证」；
   - 个人主体：身份证或支付宝快捷实名；企业主体：营业执照。
   - 状态变为「已实名」再继续（一般几分钟到几小时，.cn 需要身份信息核验）。
6. 无需急着改 DNS。先把域名留在阿里云云解析，等第 2 节拿到平台要求的记录再添加。

## 2. ChatGPT Sites 绑定自定义域名（⚠️ 步骤以平台界面为准）

官方文档（✅ 存在，绑定前先打开）：
- https://learn.chatgpt.com/docs/sites/managing-a-site
- https://help.openai.com/en-us/articles/20001339-creating-and-managing-chatgpt-sites

预期流程（⚠️ 待以实际界面核对）：
1. ChatGPT → Sites 管理 → 选中本项目站点。
2. 找到 Domains / Custom domain 入口，输入你的域名（官方帮助原文提到可输入「顶级域或子域」）。
3. 平台会显示需要添加的 DNS 记录（常见为 CNAME 指向平台域名，可能另有 TXT 校验记录）。
4. 在阿里云「云解析 DNS」控制台添加这些记录（TXT 一般几分钟生效，CNAME 按 TTL 生效）。
5. 回到 Sites 点击验证/激活，等待状态变为 active。
6. 用第 3 节方法验证国内可访问性。

已知问题（✅ 有据可查，遇到时按链接跟进最新处理）：
- 默认域名与自定义域名返回 Cloudflare 403：https://github.com/openai/codex/issues/34954
- 自定义域名卡在 active_redeploying：https://community.openai.com/t/chatgpt-sites-custom-domain-stuck-at-active-redeploying-case-15904805/1402220

## 3. 国内访问验证清单（✅）

1. 手机**关闭 WiFi、只用流量**打开你的域名（排除路由器/本地缓存干扰）。
2. 换 DNS 或开无痕窗口，确认不是浏览器缓存。
3. 用 chinaz / 站长工具「多地 Ping / 网站测速」看国内节点连通率。
4. 对照检查：能打开首页 → 打开「战术手册」进入一个战术动画 → 打开任意已发布录像（若已上传），确认 API 与媒体文件都走通了，而不是只有静态首页可访问。

## 4. 什么时候需要 ICP 备案（✅ 结论）

| 部署方式 | 需要备案 | 国内表现 |
|---|---|---|
| 自有域名 + ChatGPT Sites（Cloudflare 海外节点） | ❌ 不需要 | 能打开，时快时慢 |
| 自有域名 + 阿里云国内 CDN / 服务器 | ✅ 必须 | 稳定、快 |

备案说明（✅ 免费，流程 1–3 周）：
- 阿里云备案入口：控制台 → 「ICP 备案」。需已实名的域名、主体身份证/营业执照、人脸核验。
- 备案期间通常要求网站不能对外提供服务（按管局要求），所以建议先完成第 2 节的海外方案上线，再择期走备案迁移。
- 域名实名认证与 ICP 备案是两个不同步骤，不能互相替代。
